---
description: Draft a fees-overdue letter with the charges and payments on record.
---

Run `npm run accom -- draft-arrears-letter --contract=<resident or id> --json`.

Present the result as a short table in plain words. If a name matches more than one record the command lists them: ask which one.

Read `resident` first. If there is an open welfare concern, tell the operator before they send: money and wellbeing are often linked. Draft only.
