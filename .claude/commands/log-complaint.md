description: Add a complaint to the log residents can see.
---

Run `npm run accom -- log-complaint --building=<building> [--resident="<name>"] --summary="…" [--code-related] --actor=<name>`.

This changes records. Get the real staff name for --actor. Run it with --dry-run first, show the operator what will change, and run it for real only after a yes in this session. Never invent a date, an amount or a person.

Clause 31(5). Mark --code-related when the complaint is about a breach of the Pastoral Care Code.
