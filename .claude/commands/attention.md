Run `npm run accom -- attention --json`.

Present the result as a short table in plain words. If a name matches more than one record the command lists them: ask which one.

Lead with anything about a resident's safety (high-risk concerns, missed activity checks, plan reviews), then contracts, then money, then repairs. For each line name the person, the rule and the next step. Offer the command that fixes it (open-plan, log-check, disclose, draft-arrears-letter).
