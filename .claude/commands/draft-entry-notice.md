description: Draft the notice to residents before a room entry.
---

Run `npm run accom -- draft-entry-notice --room=<room> --entry=YYYY-MM-DDTHH:MM --reason="…" --json`.

Present the result as a short table in plain words. If a name matches more than one record the command lists them: ask which one.

Says whether sending now gives enough notice. Draft only: the operator sends it.
