---
description: The Monday review for the head of hall: occupancy, who arrives and leaves, fees overdue, welfare due, Code checks by rule, open complaints and repairs.
---

Run `npm run accom -- weekly-review --json`.

Present the result as a short table in plain words. If a name matches more than one record the command lists them: ask which one.

Write it as a one-page brief in this order: the numbers (beds, occupied, vacant), the three things to decide this week, then each section in two or three lines. Save it to `drafts/weekly-review-<date>.md`. Do not include welfare detail beyond first names and the item due: this may be read by people outside the welfare team.
