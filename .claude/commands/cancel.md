---
description: Cancel a contract that has not started or has ended. Frees the bed.
---

Run `npm run accom -- cancel --contract=<resident or id> --reason="…" --actor=<name>`.

This changes records. Get the real staff name for --actor. Run it with --dry-run first, show the operator what will change, and run it for real only after a yes in this session. Never invent a date, an amount or a person.

Check the refund policy on the contract and say what it means for the deposit. Do not record a refund as a payment.
