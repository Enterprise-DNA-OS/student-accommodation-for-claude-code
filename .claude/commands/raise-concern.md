---
description: Record a cause for concern about a resident: wellbeing, behaviour, safety, health or study.
---

Run `npm run accom -- raise-concern --resident="<name>" --category=… --risk=low|medium|high --summary="…" [--by="<who reported>"] --actor=<name>`.

This changes records. Get the real staff name for --actor. Run it with --dry-run first, show the operator what will change, and run it for real only after a yes in this session. Never invent a date, an amount or a person.

Write facts, not diagnoses. A high-risk concern needs a welfare plan: the command says so. If anyone is in immediate danger, the operator calls 111 first; this record comes after.
