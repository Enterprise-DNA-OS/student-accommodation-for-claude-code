Run `npm run accom -- resident --resident="<name>" --json`.

Present the result as a short table in plain words. If a name matches more than one record the command lists them: ask which one.

Read the whole record before answering or drafting anything about this person. Welfare detail is staff-only: never paste it into a draft that goes to the resident or a guardian.
