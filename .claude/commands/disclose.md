description: Record the day the resident was given the house rules, the complaints process (with the Dispute Resolution Scheme) and the refund policy.
---

Run `npm run accom -- disclose --contract=<resident or id> --house-rules=YYYY-MM-DD --complaints-info=YYYY-MM-DD [--refund-policy="…"] --actor=<name>`.

This changes records. Get the real staff name for --actor. Run it with --dry-run first, show the operator what will change, and run it for real only after a yes in this session. Never invent a date, an amount or a person.

Clause 31(4) of the Pastoral Care Code requires these before signing. Record only dates the operator confirms.
