---
description: Rooms with a free bed between two dates, for a new booking or a room change.
---

Run `npm run accom -- vacancies --from=YYYY-MM-DD --to=YYYY-MM-DD --json`.

Present the result as a short table in plain words. If a name matches more than one record the command lists them: ask which one.

Ask for the dates if the operator did not give them. List rooms by building with the weekly fee.
